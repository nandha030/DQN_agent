## 🎯 3 Tools in One Place:

### 1. 🌐 Web Search Tab
**Features:**
- Search the web directly from chat
- AI-powered summarization
- View sources with links
- Results appear inline

**How to Use:**
1. Go to 💬 Chat page
2. Scroll to bottom
3. Expand **"🔍 Web Search & Tools"**
4. Click **"🌐 Web Search"** tab
5. Type your search query
6. Click **"🔍 Search"**
7. Get AI summary + sources!

**Example:**
- Search: "latest Python features"
- Results: Web results + AI summary
- Sources: Clickable links

---

### 2. 📎 Attach File Tab
**Features:**
- Upload files directly to chat
- Support: PDF, TXT, DOCX, MD, JPG, PNG
- Files added to chat context
- Multi-file support

**How to Use:**
1. Go to **"📎 Attach File"** tab
2. Upload files (drag & drop or browse)
3. Click **"💬 Add to Chat Context"**
4. Files appear as chat messages
5. Ask questions about them!

**Example:**
- Upload: research_paper.pdf
- Ask: "Summarize the key findings"
- AI reads the file and responds!

---

### 3. 🎤 Voice Tab
**Features:**
- Browser-based voice input
- No backend needed
- Works in Chrome/Edge
- Instructions provided

**How to Use:**
1. Go to **"🎤 Voice"** tab
2. Copy the JavaScript code
3. Paste in browser console (F12)
4. Click microphone icon
5. Speak your message
6. Text appears in chat input!

**Browser Support:**
- ✅ Chrome (best)
- ✅ Edge (best)
- ⚠️ Firefox (limited)
- ❌ Safari (not supported)

## 🎨 Design:

**Collapsible Section:**
- Starts **collapsed** (clean interface)
- Expand when needed
- Located at **bottom of chat**
- 3 tabs for different tools

**Why Collapsed by Default?**
- Keeps chat interface clean
- Only expands when you need it
- Like ChatGPT's clean design
- Easy access when needed
