## 🧠 Core Engine Page - Detailed Features

### **📚 RAG Tab**

**File Upload:**
- Drag & drop or browse files
- Supported: PDF, TXT, DOCX, MD
- Multi-file upload
- Processing status

**Settings:**
- Enable/Disable RAG
- Documents to Retrieve (1-10)
- Min Similarity Score (0-1)

**Statistics:**
- Total Documents
- Total Chunks
- Total Queries
- Average Relevance

**Recent Retrievals:**
- Shows last 5 RAG queries
- Retrieved documents with scores
- Expandable for details

---

### **🌊 Rainbow DQN Tab**

**Metrics:**
- Total Episodes
- Average Reward (with delta)
- Epsilon (exploration rate)
- Total Steps

**Training Chart:**
- Reward over time (Plotly)
- Episode-by-episode tracking
- Visual progress monitoring

**Settings:**
- Enable/Disable Training
- Learning Rate (0.00001-0.01)
- Discount Factor γ (0.9-0.999)
- Batch Size (16/32/64/128)

**Rainbow Components:**
- ✅ Double DQN
- ✅ Dueling Networks
- ✅ Prioritized Replay
- ✅ Multi-step Returns
- ✅ Noisy Networks
- ✅ Distributional RL

---

### **👍 RLHF Tab**

**Metrics:**
- Total Ratings
- Positive Count
- Negative Count
- Approval Rate %

**Rating History:**
- Visual chart (Plotly)
- Green = positive, Red = negative
- Timeline view

**Settings:**
- Enable/Disable RLHF
- Reward Scale (0.1-2.0)
- Positive Reward (0-2.0)
- Negative Reward (-2.0-0)

**Recent Ratings:**
- Last 10 ratings
- Query + Response preview
- Thumbs up/down icon

---

### **🔥 Curiosity Tab**

**Metrics:**
- Novel States Found
- Avg Intrinsic Reward
- Exploration Steps
- Avg Novelty

**Curiosity Chart:**
- Intrinsic motivation over time
- Filled area chart (Plotly)
- Step-by-step tracking

**Settings:**
- Enable/Disable Curiosity
- Curiosity Weight β (0-1)
- Forward Model LR η (0.001-0.1)

**ICM Components:**
- Forward Model Loss
- Inverse Model Loss
- Novel patterns discovered list
